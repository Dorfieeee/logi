# Server game history

In **Settings → Game servers**, Logi can retain completed games from a configured Warcon source. Enable collection, then open **Warcon game history** to filter by period, server or map.

The overview shows faction wins, draws and games without a result. Player rankings support kills, K/D, cash, wins and win rate. The default minimum playtime is 60 minutes. Expand a game to see its final scores and players.

These are in-game factions, not clan teams. A collected game does not confirm an official match or link a Steam player to a Discord member. Missing values appear as a dash; unknown results are not losses. Metric coverage is shown alongside totals.

History survives disabling collection and credential rotation. Logi checks for new games every ten minutes and re-reads every game once a day, so a correction made in Warcon updates the existing game within a day. Coverage starts with successfully imported games: Logi cannot reconstruct games that disappeared from Warcon before collection.

**History retention** in the same section keeps retained games indefinitely by default. A manager can instead choose 90, 180, 365 or 730 days; games that ended before that window are deleted permanently in a nightly sweep (and immediately after the window is shortened). Deletion advances the history revision, so a website scanning `/api/v1/clan/server-game-history` receives `reset_required` and rebuilds its totals from the remaining games. Deleted games cannot be recovered from Logi.

Invalid provider data, including repeated faction names, is rejected. The last successfully retained games remain available; a failed import does not add wins or replace valid history.

Administrators can give a website backend a read key with **Retained server games** and **Wardogs** access. This includes player names and platform IDs, so keep the key on the backend and choose which fields the public website displays. The `/api/v1/clan/server-game-history?game=wardogs` endpoint supplies revision-consistent pages. A website must finish all pages before showing totals, and restart a scan if the API returns `reset_required`.

See the [API reference](/api-reference) for the structured contract. This feature currently supports Warcon completed games; official clan/League results and verified membership retain their separate workflows.


## Wardogs score timelines

New Warcon imports retain up to 500 actual score samples, preserving the first
and last sample. Each sample contains elapsed seconds and the faction scores
in provider order. Older imports can have no timeline. Confirming a match
result captures a reviewed report using these source facts; later provider
changes do not silently rewrite that report. Unknown money remains unknown.
See [Matches](/wiki/operations/matches) for review, suggestions and personal recaps.
